# 银鳞 · Codex 龙娘桌宠

Windows 透明桌宠便携版。银白 Q 版龙娘陪你工作，在气泡中显示真实的 Codex 五小时、一周剩余比例，以及逐秒更新的系统时钟。

## 下载和运行

在本仓库的 **Releases** 页面下载 `SilverDragonPet-v1.0.0-win-x64-portable.zip`，完整解压后双击 `SilverDragonPet.exe`。不要直接在压缩包内运行。

适用于 Windows 10 / 11 x64，使用 .NET Framework 4.8，无需安装 Node 或 Python。余量和聊天需要本机已安装 Codex，并通过 ChatGPT 账号登录。

更新时请先右键退出旧版，再运行新版。程序已运行时，再次启动会找回隐藏的桌宠。

## 功能

- 银白龙娘、24 帧姿态，9 类手动动作和 15 种互动。
- 真实 Codex 余量、重置时间、数据来源和每秒系统时钟。
- 动作平滑过渡，连续选择动作可接续当前画面；动作节奏已放慢，常用互动停留约 3.5～3.8 秒。
- 右键可聊天、查看状态、暂停自主活动、跟随鼠标、自由走动或固定位置。
- 可设置大小、透明度、移动速度、特效、置顶、显示气泡和查询间隔。
- 托盘或再次启动程序可恢复隐藏组件。

按住角色拖动位置，点击互动，在角色上右键打开完整功能菜单。设置会保存在程序旁的 `settings.json`。

## 聊天与余量

打开聊天窗口不会自动发送消息。主动发送后使用已登录的 Codex 账号对话，会使用 Codex 额度；支持流式回复、停止和开始新对话。

气泡百分比表示对应 Codex 额度窗口的剩余比例，不是 Token 数量。默认每 60 秒查询，右键可刷新；接口不可用时可显示带来源提示的本地记录。系统时钟每秒更新。
